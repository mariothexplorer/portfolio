Web app (iOS simulation)

Уеб приложение (iOS симулация)

This interactive mobile simulation replicates an iPhone environment, built using HTML, CSS and JavaScript. The project focuses on interface structure, user interaction logic and visual realism and is fully interactive.

Тази интерактивна мобилна симулация пресъздава среда на iPhone, изградена с HTML, CSS и JavaScript. Проектът се фокусира върху структурата на интерфейса, логиката на потребителските взаимодействия и визуалния реализъм, като е напълно интерактивен.

This project showcases my ability to create web applications with the help of Artificial Intelligence. Most of the code was generated by different AI chat models.

Този проект демонстрира способността ми да създавам уеб приложения с помощта на изкуствен интелект. По-голямата част от кода беше генерирана от различни ИИ чат модели.

By building this project I learned how to create and optimise prompts in order to get the desired result from the AI chat models. Additionally, by editing the code, I learned the basics of HTML, CSS and JavaScript.

Чрез изграждането на този проект се научих как да създавам и оптимизирам промптове, за да получа желания резултат от ИИ моделите. Допълнително, чрез редактиране на кода, научих основите на HTML, CSS и JavaScript.

The simulation can be started by swiping up from the white line at the bottom of the screen (as in a real iPhone). Users are led to a password screen. The password is "123456". After entering a correct password, users are led to the main screen of the simulation.

Симулацията може да се стартира чрез плъзгане нагоре от бялата линия в долната част на екрана (както при истински iPhone). Потребителите се отвеждат до екран за въвеждане на парола. Паролата е "123456". След въвеждане на правилна парола се отваря главният екран на симулацията.

All apps except for voice memos are active. They are not fully developed, but they are interactive and can be used to test the user interface and user experience.

Всички приложения, с изключение на гласовите бележки (voice memos), са активни. Те не са напълно разработени, но са интерактивни и могат да се използват за тестване на потребителския интерфейс и изживяване.

An additional improvement that I plan to make is to make all apps fully responsive and mimic most of the features of the real apps. Moreover, I plan to add more apps to the simulation.

Допълнително подобнение, което планирам, е да направя всички приложения напълно адаптивни и да имитират повечето от функциите на реалните приложения. Освен това планирам да добавя още приложения към симулацията.
